## ⚙️ Requirements

To follow the practical examples, you will need:

- **Python 3** installed on your computer.
- A code editor such as [Visual Studio Code](https://code.visualstudio.com/).
- A willingness to learn and experiment!

Download Python from the official website:

👉 https://www.python.org/downloads/

To check whether Python is installed, open your terminal or command prompt and run:

```bash
python --version
```

On some Windows installations, you may need:

```bash
py --version
```

Follow these simple steps to get started.

### 1. Clone the repository


### 2. Open the project

Open the downloaded folder in Visual Studio Code or your preferred code editor.

### 3. Start with the basics

Begin with the introductory Python tutorial, then continue through variables, data types, operators, and other available topics in order.

### 4. Practise the examples

Read each explanation, run the code, and experiment by changing values or adding your own instructions.

Once you understand a concept, try using it in a small program without copying the example directly.

## 💻 Your First Python Program

Here is a simple example of Python in action:

```python
# My First Python Program

name = input("Enter your name: ")

print("Hello,", name)
print("Welcome to the world of Python!")
```

### Example Output

```text
Enter your name: Soura
Hello, Soura
Welcome to the world of Python!
```

This small program introduces variables, user input, and output. These are some of the fundamental building blocks of Python programming.
